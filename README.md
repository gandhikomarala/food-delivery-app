# BiteRush Gourmet — Artisanal Culinary Logistics Platform

End-to-end culinary ordering platform featuring dynamic menu curation, dietary filter chips, live GPS delivery courier simulation, interactive cart, tip calculator, and checkout workflow.

## Product Highlights
- **Domain**: E-Commerce / Food
- **Visual Theme**: Warm Foodie Ember & Cream Ochre
- **State Persistence**: Browser localStorage & FastAPI microservices
- **Zero-Dependency Web Client**: Works seamlessly on GitHub Pages

## Architecture & Quick Start
```bash
# Run Tests
pytest tests/

# Docker Deployment
docker-compose up -d --build
```
